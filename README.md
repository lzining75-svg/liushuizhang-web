# 流水账 · 使用教程

流水账是一款以聊天方式记录支出的个人记账工具，支持多账本、支出统计、循环预算和自定义分类。

使用地址：https://lzining75-svg.github.io/liushuizhang-web/

## 1. 添加到手机主屏幕

1. 使用 iPhone 的 **Safari 浏览器**打开上面的网址。
2. 点击“分享”按钮，选择“添加到主屏幕”。
3. 如果出现“作为网页 App 打开”选项，将它开启。
4. 点击“添加”，之后就可以从桌面图标打开流水账。

无需开启开发者模式，也不需要连接电脑。建议添加到主屏幕后，再开始正式记账或导入旧账目。

## 2. 记一笔支出

进入“账本”，打开“日常账本”或其他账本，在输入框中发送“用途＋金额”，例如：

- `午饭28`
- `咖啡18.5`
- `地铁6`

系统会自动记录用途、金额和当前时间，并根据关键词匹配分类。无法识别的用途会归入“其他”。

每条消息记录一笔支出，金额最多保留两位小数。目前仅支持支出记账。

## 3. 修改或删除账单

点击聊天气泡，或统计明细中的某笔支出，即可修改：

- 用途
- 金额
- 分类
- 时间
- 所属账本

在修改窗口中点击“移入回收站”可以删除账单。误删后，可到 **设置 → 回收站**恢复；永久删除后无法恢复。

## 4. 管理多个账本

在“账本”页面点击右上角的“＋”创建新账本，例如“旅行”“家庭”“宠物”。

“日常账本”会置顶，并使用稍深的背景区分。

进入 **设置 → 账本照片与名称**，可以设置账本照片或修改自建账本的名称。

## 5. 查看统计与趋势

“统计”页面包含四个选项：

- **本日／本月／本年**：查看总支出、分类分布、账本分布及各账本汇总。
- **趋势**：按日、月、年查看历史支出。

趋势中的“日”使用日历展示，每个日期显示当天金额，并通过颜色深浅区分支出大小。“月”和“年”使用柱状图展示。

点击日期、柱子或对应的金额列表，可以查看该期间的支出明细。

底部始终汇总本日、本月和本年的总支出。

## 6. 设置循环预算

进入“预算”，点击右上角“＋”，填写预算金额，并选择：

- 每月循环
- 每年循环
- 自定义每 N 天、周、月或年循环

预算从创建当天开始计算，并按周期自动进入下一轮。例如，10 月 28 日创建的每月预算，会在 11 月 28 日开始下一轮。

预算可以针对全部账本，也可以只针对某个账本或某个分类。点击已有预算，可以编辑或移入回收站。

## 7. 自定义外观和分类

在“设置”中可以：

- 切换全局配色。
- 选择跟随系统、浅色或深色外观。
- 修改昵称和头像。
- 添加或删除支出分类。
- 点击“支出分类 → 排序”，拖动右侧手柄调整顺序。

添加分类时，可以填写识别词，多个词用逗号分隔，例如“捐赠、助学”。

删除分类后，相关账单和预算会归入“其他”。“其他”分类不能删除，但可以调整位置。

## 8. 备份与迁移账目

进入 **设置 → 备份与数据**：

- **导出完整备份**：保存账目、预算、分类、照片及设置，适合备份或换手机。
- **导入备份**：支持流水账网页版及当前 iPhone 原生版导出的完整 JSON 备份。
- **导出支出 CSV**：方便使用表格软件查看支出。
- **恢复上次本地副本**：恢复上一次保存前的本地数据。

导入会替换当前浏览器里的账本，请先确认备份内容，并提前导出当前账本。

## 9. 数据保存与更新

**账目保存在当前设备的浏览器存储中，不会上传到 GitHub，也不会在两台手机间自动同步。**

请注意：

- 更换手机或浏览器前，先导出完整备份。
- 不要使用无痕浏览模式长期记账。
- 清理网站数据、移除主屏幕网页 App 或浏览器回收存储，都可能导致数据丢失。
- Safari 与主屏幕网页 App 的存储可能独立，必要时使用备份迁移。

首次联网打开并完成缓存后，可以离线记账。以后网站发布新版，联网重新打开或刷新即可获取更新，不需要连接电脑或定期重新安装。
