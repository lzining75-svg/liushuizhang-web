# 流水账

手机优先的个人记账网页：聊天记账、多账本、支出统计、热力日历、月/年柱状图、循环预算、分类拖动排序和备份。

数据仅保存在当前浏览器。仓库和网站不包含任何用户账目。两台设备不会自动同步，请定期导出完整备份。可以导入 iPhone 原生版“流水账”的完整 JSON 备份。

在 iPhone Safari 打开网站，分享 → 添加到主屏幕，即可使用独立窗口。不需要苹果开发者会员或开发者模式。首次联网加载及缓存后支持离线打开；清理网站数据或浏览器回收存储可能造成数据丢失，请定期导出备份。

此为纯静态网站，无外部依赖。GitHub Pages 使用默认分支的根目录发布，`.nojekyll` 保持模块文件原样分发。
